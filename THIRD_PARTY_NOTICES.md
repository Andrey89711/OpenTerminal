# Third-party notices

## Windows Terminal color schemes

The nine built-in color schemes in `src/schemes.ts` are adapted from Microsoft
Windows Terminal's official presets (retrieved 2026-11-11):

- https://github.com/microsoft/terminal
- https://raw.githubusercontent.com/microsoft/terminal/main/src/cascadia/TerminalSettingsModel/defaults.json
- https://raw.githubusercontent.com/microsoft/terminal/main/LICENSE

Palette, foreground, background and explicit cursor/selection values are preserved.
Where the upstream preset omits selectionBackground, the Windows Terminal default
of white is supplied to satisfy OpenTerminal's complete scheme model.
